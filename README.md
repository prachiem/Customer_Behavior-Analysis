# Customer_Behavior-Analysis

## 📌 Overview

This project demonstrates an end-to-end data analytics workflow using **Python, SQL, and Power BI**.
The goal is to extract insights from raw data by performing data cleaning, exploratory data analysis (EDA), SQL-based querying, and interactive dashboard creation.
It showcases practical skills required for a **Data Analyst role**, including data handling, querying, visualization, and reporting.

## 📂 Dataset

* The dataset contains structured transactional/business data.
* Includes multiple attributes such as categories, time-based fields, numerical metrics, and identifiers.
  
<a href="https://github.com/prachiem/Customer_Behavior-Analysis/blob/main/customer_shopping_behavior.csv">Dataset</a>

## 🛠 Tools & Technologies

* **Python**: Data loading, cleaning, and EDA

  * Libraries: Pandas, NumPy, Matplotlib, Seaborn
* **SQL**: Data querying and analysis

  * Databases: PostgreSQL / MySQL / SQL Server
* **Power BI**: Interactive dashboard creation
* **Jupyter Notebook**: Analysis and documentation
* **GitHub**: Version control and project hosting
  
## 🔍 Project Steps

1. **Data Loading**

   * Imported the dataset into Python using Pandas.
   * Verified data structure and data types.

2. **Exploratory Data Analysis (EDA)**

   * Analyzed distributions, trends, and relationships.
   * Identified missing values and outliers.
   * Generated summary statistics and visualizations.

3. **Data Cleaning**

   * Handled missing and inconsistent values.
   * Removed duplicates and corrected data types.
   * Prepared clean data for analysis and reporting.

4. **SQL Analysis**

   * Loaded cleaned data into PostgreSQL/MySQL/SQL Server.
   * Wrote SQL queries for aggregation, filtering, joins, and trend analysis.
   * Extracted insights to support business questions.

5. **Dashboard Development**

   * Connected Power BI to the database / cleaned dataset.
   * Built interactive visuals such as KPIs, charts, and filters.
   * Designed a user-friendly dashboard for decision-making.

## 📊 Results & Insights

* Identified key trends and patterns in the data.
* Highlighted top-performing and underperforming segments.
* Provided actionable insights supported by SQL queries and visualizations.
* Enabled data-driven decision-making through an interactive dashboard.

## 📈 Dashboard

The Power BI dashboard provides:

* Key performance indicators (KPIs)
* Trend analysis over time
* Category-wise and segment-wise breakdowns
* Interactive filters for deeper exploration
